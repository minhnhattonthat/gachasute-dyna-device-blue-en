# VWF font for the 8x8 text cells (size 3) and, offset down 2 rows, the 16x16 cells (size 1). Drawn for this
# project (MIT, docs/fonts.md). One glyph per block: a line "= C" (C = the character; "= space" for 0x20), then 8
# rows of '#' (ink) and '.' (blank); the row length is the ink width, the advance is width + 1. Rows 0-6 hold caps
# and digits (baseline under row 6, as the game's own glyphs), row 7 the descenders. Edit freely; tools/vwf.py
# reads it and tests/test_vwf.py checks every block.
